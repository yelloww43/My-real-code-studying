## 打包 C++ 练习代码（分享用）

**背景**：工作区 `E:\vs c++` 下有 46 个 Visual Studio C++ 练习项目，共 1234 个文件、3.6 GB，其中绝大部分是编译中间产物（.tlog / .pdb / .idb / .ipch / .db）。

**目录结构规律**（46 个项目全部一致）：
```
<项目名>/
├── <项目名>.sln
├── <项目名>/            ← 项目文件夹
│   ├── <项目名>.cpp     ← 唯一源码（每项目 1 个 .cpp，无 .h）
│   ├── <项目名>.vcxproj
│   ├── <项目名>.vcxproj.filters
│   └── x64/             ← 编译产物，不打包
└── x64/                 ← 编译产物，不打包
```

**产物**：`output/20260924-cpp-code-pack/C++练习代码_源码包.zip`
- 0.15 MB（3.6 GB → 0.15 MB），184 个文件 + README.txt
- 打包脚本留在同目录：`_build_zip.py`（新增项目后可直接重跑）

**打包规则**（白名单）：只收 `.cpp/.h/.hpp/.c/.sln/.vcxproj/.filters/.md/.txt`；跳过目录 `x64 x86 .vs Debug Release ipch output __pycache__ .git`；排除 `.vcxproj.user`（含本机路径）。
zip 内统一加 `C++练习代码/` 根前缀，解压即得完整文件夹。README 用 `utf-8-sig`（BOM）写入，避免 Windows 记事本中文乱码。

**踩坑**：生成中文对齐表格时不能用 `%-28s` 按字符数补齐——中文显示宽度是 2。需按 `unicodedata.east_asian_width(ch) in ('W','F')` 计算显示宽度后手工补空格。

**下一步（用户可能用到）**：如果他还想连编译产物（可运行 exe）一起发，需要另打一个包含 `x64/Release/*.exe` 的包。
