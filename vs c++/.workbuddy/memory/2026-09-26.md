## 新增交付：一键重新打包.bat

路径：`output/20260924-cpp-code-pack/一键重新打包.bat`
双击即可重跑 `_build_zip.py`，无需命令行。已验证可正常运行（输出中文正常）。

**技术要点**（重要，以后写 .bat 都照这个来）：
- .bat 内容**全部用 ASCII**，不写中文——.bat 按系统 ANSI 代码页逐行解析，UTF-8 中文会乱码。中文提示交给 Python 打印（脚本内已 `sys.stdout.reconfigure(encoding="utf-8")`），.bat 里配 `chcp 65001` 即可正常显示。
- 用 `%~dp0` 定位同目录的 .py，避免依赖当前工作目录。
- 底层 .py 用绝对路径 `ROOT = r"E:\vs c++"`，所以 .bat 从哪双击都行。
- `pause >nul` 防止窗口一闪而过。
